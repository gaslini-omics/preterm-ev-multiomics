# data/

This folder contains the small input files distributed with the repository:

- `techrep/proteomics/`: Spectronaut exports of the technical replicates (pooled adult plasma)
- `techrep/lipidomics/sample_meta_C18_{pos,neg}.txt`: sample annotation of the technical replicates
- `reference/`: EV reference panels (Rai *et al.*, *Nat. Cell Biol.* 2025) and the MISEV2023 category assignment
- `metadata/sample_metadata_TEMPLATE.txt`: column layout of the (not distributed) sample metadata

All other inputs, with their expected paths and sources, are listed in the main README under *Input files*.
